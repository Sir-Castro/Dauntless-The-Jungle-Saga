Abstract

Purpose: Dauntless: The Jungle Saga is an interactive 2D side-scrolling action-shooter and platformer game designed to provide high-stakes combat through a hazardous jungle environment. It serves as both an entertainment medium and a technical demonstration of projectile physics, AI systems, and real-time collision detection.

Technologies: The work is built upon a proprietary 2D Canvas-based rendering engine implemented in JavaScript (ES2023+) and React 18. It utilizes the Capacitor 8.0 runtime for mobile deployment and Vite 5 for optimized state management and asset delivery.

Platforms: Primary deployment target is Android (API Level 24+), with architectural support for Progressive Web App (PWA) distributions.

Introduction

Developed as a modern homage to classic run-and-gun platformers, Dauntless: The Jungle Saga pushes the boundaries of web-based game engines with its implementation of Continuous Collision Detection (CCD) for high-speed projectiles and dynamic AI behaviors for raiders, zombies, and defensive turrets. This documentation outlines the software's functional logic, visual presentation, and underlying source code for the purpose of copyright registration and archival.

The following sections provide a sequenced walkthrough of the software's operational flow, from initialization through to the core combat loop, level objectives, and victory states.

Functional Documentation (User Interface & Workflow)

1. Access, Initialization & Loading: The software begins with a high-performance Splash Screen that initializes the asset pipeline and pre-fetches game states. This ensures a seamless transition into the interactive environment.

Menu Navigation:
The Main Menu serves as the central hub, providing access to "Level Selection", "Achievements", and player settings.
Core Mechanics:
Engagement relies on fluid character movement (running, jumping), intense shooting mechanics, dodging vertical turret bursts, and utilizing grenades against varying enemy types like raiders and zombies. Continuous Collision Detection ensures fair gameplay.
Progression Hub:
Players advance through multiple stages and levels, each with distinct environments and objectives (e.g., Turret Destruction, Zombie Elimination).
